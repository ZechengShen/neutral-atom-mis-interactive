# 中性原子 MIS / MWIS 互动演示

一个面向教学的中文交互网页，用图形和策略关卡介绍：

- 最大独立集（MIS）与最大权重独立集（MWIS）
- 天线信号、基站调度和任务排程的冲突图建模
- 冲突图到中性原子 Rydberg blockade 的概念映射
- 十道 MIS 策略挑战与五道 MWIS 权重挑战
- 自定义几何编辑、固定权重显示与答案反馈
- 每轮 1000 次的本地 Rydberg 模型采样、得分分布与最优成功率

第 11—15 关使用 12—18 个节点，依次为“重权迷阵”“花轮博弈”“双环齿轮”
“双桥对弈”和“同权异构”。第 14 关使用双轮双桥结构考察跨区域权衡，第 15 关以
不同节点数但同权的最优解收束。五关都会让简单的“最高权重优先”策略得到次优解；
节点大小也会随权重适度变化，同时保留稳定的点击热区。

## 在线使用

打开仓库右侧的 GitHub Pages 网站即可，无需安装软件。

## 本地使用

下载 `index.html` 并用现代浏览器打开。网页不依赖网络、数据库或第三方运行时。

## 科学边界

页面中的 blockade 圆是有效教学模型。小态空间由浏览器执行硬 blockade 受限态矢演化；大态空间自动切换为终态能量的局域近似。任意冲突图映射到二维原子阵列时，可能仍需几何嵌入、辅助原子或其他编译步骤。本演示不声称连接了真实量子硬件，也不作量子加速结论。
